# TradeDemoBase — учебная конфигурация 1С:Предприятие 8.3

Учебный проект для освоения разработки на платформе 1С:Предприятие 8.3. 
Реализован простой товароучёт: поступление, расход, перемещение товаров между складами, 
отчёты по остаткам и оборотам.

## 📦 Состав конфигурации

### Справочники
- **Товары** — номенклатура.
- **Склад** — список складов.

### Документы
- **Поступление** — приход товара на склад.
- **Расход** — списание товара со склада.
- **Перемещение** — перемещение товара между складами (расход с одного, приход на другой).

### Регистры накопления
- **ОстаткиТоваров** — учёт остатков товаров в разрезе складов.
  - Измерения: `Товар`, `Склад`.
  - Ресурс: `Количество`.

### Отчёты (СКД)
- **ОстаткиТоваров** — остатки на дату, с группировкой `Склад → Товар`.
- **ОборотыТоваров** — обороты за период (приход, расход, остаток), с группировкой `Склад → Товар`.
- **КарточкаТовара** — движение конкретного товара за период.

### Пользовательские настройки отчётов
- Отбор по складу и товару.
- Группировка `Склад → Товар`.

## 🛠️ Стек

- **Платформа:** 1С:Предприятие 8.3
- **Среда разработки:** 1C:Enterprise Development Tools (EDT)
- **Язык:** встроенный язык 1С
- **Контроль версий:** Git (GitHub)
- **Java:** Axiom Full JDK (для работы EDT)

## 🚀 Как запустить

1. Установить 1С:Предприятие 8.3 (учебная версия).
2. Установить 1C:EDT и Axiom Full JDK.
3. Клонировать репозиторий:
   ```bash
    git clone https://github.com/MilkyHouse11/TradeDemoBase.git
   ```
4. Импортировать проект в EDT.
5. Создать информационную базу и запустить.
